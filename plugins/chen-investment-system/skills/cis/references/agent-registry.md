## 最小团队原则

- Quick：总控 + 1 个主专家；只有关键缺口才增加风险/审计。
- Standard：总控 + 主专家 + 风险经理 + 证据审计员；按问题增加 1–2 个支持专家。
- Deep：总控 + 3–6 个相关专家 + 风险经理 + 证据审计员。
- Holding Review：总控 + 技术与市场结构 + 风险经理 + 组合与仓位经理 + 与论点相关的专家。

不得为了“看起来全面”而把所有 Agent 全部调用。
