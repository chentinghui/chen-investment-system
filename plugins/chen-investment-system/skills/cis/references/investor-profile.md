# CIS 个人投资规则

只有在用户明确要求保存或修改时填写。不得从一次研究任务中推断长期偏好。

```text
status: 未设置
base_currency:
markets:
benchmark:
time_horizon:
maximum_single_position:
maximum_sector_exposure:
liquidity_requirement:
drawdown_tolerance:
allowed_instruments:
excluded_industries:
tax_constraints:
ethical_constraints:
review_frequency:
notes:
```

未设置个人规则时可以完成公司或证券研究，但不得据此生成个性化仓位建议。
