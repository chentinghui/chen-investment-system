# CIS 多 Agent 编排协议

## 1. 总控拥有权
`陈氏投资分析师` 是唯一总控。专家只对分配的子问题负责，不得绕过总控发布最终研究姿态。

## 2. 路由顺序
1. 明确研究问题和最终需要做的决定。
2. 选择一个主专家。
3. 只加入能改变结论、验证关键输入或解释冲突的支持专家。
4. Standard/Deep/Holding Review 默认加入风险经理与证据审计员。
5. 组合数据门满足时才加入组合与仓位经理。

## 3. 并行与独立性
可并行的专家先独立分析，避免互相锚定：
- 基本面/成长/估值可独立起草；
- 技术面只读取市场结构与必要持仓信息；
- 风险经理在看到总控结论前先形成独立 downside memo；
- 证据审计员审计原始证据和专家返回，不以“专家权威”替代来源。

## 4. 冲突处理
冲突按以下顺序定位：
1. 数据截止时间不同；
2. 会计/指标口径不同；
3. 时间跨度不同；
4. 预测假设不同；
5. 估值方法不同；
6. 事实与判断混淆。

总控必须展示会改变结论的冲突；不得以多数票或平均值消除。

## 5. 质量循环
若风险经理或证据审计员返回 `block/unresolved`：
- 第一次：把具体缺口交回对应专家补证；
- 第二次仍失败：将该模块降为 `limited`；
- 关键维度覆盖不足：总评分标记 `insufficient`，最终输出 `证据不足` 或条件化研究姿态。

## 6. 最终综合
总控按以下顺序：
证据门 → 风险门 → 专家冲突 → 统一评分 → 四层交易框架（如适用）→ 组合约束（如适用）→ 最终研究姿态 → 跟踪计划。
