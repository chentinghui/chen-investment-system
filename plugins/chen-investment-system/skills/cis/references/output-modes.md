# CIS 输出模式

## Quick：快速筛选

适用于“简单看一下”“值不值得继续研究”。输出：

1. 一句话研究姿态。
2. 三项最关键依据。
3. 三项主要风险或缺口。
4. 本次就绪度、资料截止时间和下一步。

不得输出未经充分支持的目标价或仓位动作。

## Standard：标准研究

默认模式。输出顺序：

```markdown
## CIS 研究结论
- 研究姿态：
- 综合置信度：
- 本次就绪度：
- 资料截止时间：
- 一句话理由：

## 研究问题与范围

## 证据登记

## 模块结论

## 估值与情景

## 主要风险与证伪条件

## 跟踪计划

## 资料限制与下一步
```

## Deep：深度研究

在 Standard 基础上增加：

- 完整业务和行业结构。
- 历史财务标准化与预测驱动。
- 至少两种适用估值方法或说明为何只能使用一种。
- 基准、上行和下行情景及关键敏感变量。
- 反方论点、市场隐含预期和论点证伪路径。
- 来源、假设、冲突和待补资料附录。

## Holding Review：持仓复盘

必须先满足组合数据门。输出：

- 当前持仓、权重、成本、组合和基准影响。
- 原始论点与本次变化。
- 维持、考虑增持、考虑减持、考虑退出或暂不操作。
- 动作成立条件、风险预算和下次复盘触发点。
