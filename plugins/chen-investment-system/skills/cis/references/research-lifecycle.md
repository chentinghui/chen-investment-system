# CIS 研究生命周期

每项持续研究使用稳定的 `research_id`，并保留：

```text
research_id:
subject:
version:
created_at:
last_reviewed_at:
data_cutoff:
current_posture:
core_thesis:
key_assumptions:
thesis_falsifiers:
monitoring_indicators:
next_event:
next_review:
change_since_prior:
```

## 生命周期

1. **Screened**：完成快速筛选。
2. **Researching**：正在补充关键证据。
3. **Watchlist**：论点可理解，但估值、催化剂或资料仍不满足。
4. **Holding**：仅在用户确认实际持仓后使用。
5. **Review required**：触发证伪条件、重大事件或资料过期。
6. **Closed**：用户明确结束跟踪或论点已失效。

每次复盘优先回答“与上次相比发生了什么变化”，再重复不变事实。
